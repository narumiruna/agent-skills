# Designing User Interfaces (Deprecated Reference)

Use `designing-user-experiences` for the maintained workflow. Its bounded-surface mode preserves the former `$designing-user-interfaces` proposal, review, and implementation behavior without imposing the approval gate reserved for substantial cross-surface experience changes.

For compatibility, inspect the current interface, platform, design system, capabilities, states, and accessibility conventions before simplifying. Preserve behavior, data semantics, permissions, persistence, recovery, and unrelated capability unless the requested change authorizes otherwise.

Prioritize clear hierarchy, visible critical actions and state, predictable progressive disclosure, recognition over recall, accessible operation, proportionate feedback, responsive adaptation, and recovery. Audit both overload and false simplicity, then report the result, checks, trade-offs, and unverified scenarios.
