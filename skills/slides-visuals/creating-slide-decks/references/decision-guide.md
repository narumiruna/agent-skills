# Slide Module Decision Guide

Load the smallest set of focused skills that can produce and validate the requested artifact.

| Request | Use |
| --- | --- |
| Author or revise slides | `authoring-marp-slides` |
| Create or adapt a palette | `designing-slide-colors` |
| Create a conventional flow, sequence, ER, class, or state diagram | `creating-mermaid-diagrams` |
| Create a bespoke vector composition or exact SVG | `creating-svg-illustrations` |
| Complete branded deck | colors, authoring, then only the visual skill each diagram needs |

## Progressive Loading

1. Start with the selected skill's `SKILL.md`.
2. Load one reference for the immediate syntax, strategy, or pattern question.
3. Load troubleshooting only after a concrete problem appears.
4. Validate in the target deck; source checks alone do not prove rendered quality.

Prefer Mermaid when editable text source and conventional automatic layout fit. Prefer hand-authored SVG when exact placement, custom illustration, or renderer independence matters.
